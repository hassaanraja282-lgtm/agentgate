How it works

    
    
      
  1. Protect (/pii) finds names, emails, phone numbers, card and bank numbers, addresses and secrets, and returns a masked copy. Only the masked copy goes further down the pipeline.
    2. 
      
  2. Guard (/injection) reads the content as untrusted data in the context of your agent's task and quotes the passages that try to take over the agent.
    3. 
      
  3. Inspect (/script) runs only when the content contains a script or command lines. It reads the code without executing it and points to the risky lines.
    4. 
      
  4. Decide (/decide) weighs the three signals and the masked text against a written policy and returns allow, review or block with probabilities, the concerns behind them, and whether the agent may act without asking. An uncertain allow (under 70%) or a failed check becomes review: the gate fails closed.
    5. 
      
  5. Fill (/fill) turns the masked content into an audit record (type, summary, requested actions, pressure, links) you can download as JSON. The record keeps a SHA-256 of the content, never the content itself.
    6.
